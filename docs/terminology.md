# Terminology

Use these terms consistently in Docua documentation.

| Concept | Approved term | Avoid |
| --- | --- | --- |
| Installed add-on | Extension | Plugin, replacement application |
| Installation archive | OXT | App bundle |
| Editable document surface | Document canvas | Embedded editor website |
| Tabbed command area | Ribbon | Navbar |
| Right-hand controls | Sidebar | Side thing |
| Personal LibreOffice configuration | User profile | Document database |
| Return to original controls | Restore | Reset all data |
| Connection to LibreOffice APIs | Adapter | Document engine |
| Connection to macOS views | Native bridge | LibreOffice fork |
